# AI Trading Content Factory

Educational trading-content automation for Bullseye Theory.

## Current pipeline
Topic discovery -> educational research -> fact-review status -> script -> safety check -> visual plan -> caption/hashtags -> human approval queue.

## Safety
This project is for educational content only. It does not place brokerage orders or execute trades.

## Current mode
GitHub Actions runs the starter pipeline in MOCK_MODE. Live APIs should be added later through GitHub Secrets, never hard-coded in source files.
