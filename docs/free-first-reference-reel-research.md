# Free-first reference Reel research workflow

Purpose: study public trading-education Reels to identify reusable *format patterns* while producing original Bullseye Theory scripts and visuals.

## Reference inputs
- Use only public posts or URLs/screenshots the project owner supplies or can access normally.
- Record account, URL, date checked, topic, opening-hook pattern, pacing, visual pattern, on-screen text density, CTA type, and visible public engagement if available.
- Do not download private content, bypass logins/paywalls, evade platform controls, or copy another creator's script, footage, branding, or exact visual composition.
- Public engagement numbers are snapshots, not proof that a Reel caused growth or sales.

## What to extract
1. Hook *mechanic* (question, misconception, contrast, story, checklist), not verbatim wording.
2. One learning outcome and the sequence used to explain it.
3. Visual grammar (chart close-up, labels, split-screen, step counter, captions).
4. Approximate duration and speaking pace, when observable.
5. CTA category (save, follow, comment, course preview), not copied copy.
6. Educational accuracy, risk language, and whether any live claim needs a primary source.

## Free-first production path
1. Research/outline: ChatGPT web search or manual review of public URLs supplied by the owner.
2. Original script: deterministic fallback in this repository; optional LLM only if a genuinely free quota is available. Never add a paid API or key without explicit approval.
3. Visuals: repository's Pillow/FFmpeg renderer and generated illustrative charts.
4. Voice: Edge TTS attempt, with local espeak-ng fallback.
5. QA: check factual scope, readability, audio/video duration, captions, disclaimer, and no fabricated performance claims.
6. Delivery: GitHub Actions artifact for manual review. Never auto-publish from the draft workflow.

## Safety and rights
Reference posts are for learning broad creative patterns. Write fresh wording, use original visuals, cite sources for factual/current claims, and avoid implying endorsement or affiliation. Use illustrative charts unless verified market data is intentionally sourced and timestamped. Educational content is not personalized financial advice.
