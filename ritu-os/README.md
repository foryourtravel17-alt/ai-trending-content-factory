# Ritu AI Creator OS

A separate, free-first creator-automation workspace for the Ritu Khichar AI influencer project.

## Scope
- Character/360 reference management
- 2–3 posts/day content queue
- Fresh adult lifestyle, attraction, dating, romance and non-graphic fantasy discussion scripts
- AI image/video prompt library
- Approval workflow
- Instagram/Meta publishing readiness
- Telegram funnel
- Analytics and monetization planning

## Safety / authenticity
- Ritu is treated as an adult AI character.
- Keep required AI disclosure enabled.
- Publishing requires explicit account authorization; no credential bypassing.
- No graphic sexual content in automated public content.

## Free-first architecture
The initial dashboard is static and can be hosted without Replit Agent credits. External AI generation and Instagram publishing require the user’s authorized API/provider credentials.
